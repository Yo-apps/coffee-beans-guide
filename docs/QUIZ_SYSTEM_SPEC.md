# コーヒー豆クイズ生成システム仕様書

## 1. システム概要

### 1.1 目的
- ユーザーのコーヒー豆に関する知識を楽しく深める
- 適切なコーヒー豆選びをサポートする
- コーヒーの多様な側面への興味を喚起する

### 1.2 対象ユーザー
- コーヒー初心者
- コーヒーについて学びたい人
- コーヒー豆選びに迷っている人

## 2. システム要件

### 2.1 機能要件

#### 2.1.1 クイズ生成
- ナレッジベースからランダムにトピックを選択
- GEMINIを使用した自然な質問文の生成
- 難易度レベルの自動調整
- 複数の選択肢と詳細な解説の生成

#### 2.1.2 データソース
- Web上のコーヒー関連情報
- 信頼性の高い情報源からの収集
- 多言語対応（日本語・英語）
- 定期的な情報更新

#### 2.1.3 クイズの種類
- 基礎知識
- 豆の特徴
- 焙煎度
- 産地情報
- 抽出方法
- 保存方法

### 2.2 非機能要件

#### 2.2.1 パフォーマンス
- クイズ生成時間：3秒以内
- 同時リクエスト処理：最大10件
- GEMINI API使用量の最適化

#### 2.2.2 信頼性
- 情報の正確性確保
- ソース情報の明記
- 定期的な内容検証

#### 2.2.3 拡張性
- 新しいトピックの追加容易性
- クイズ形式の拡張可能性
- 多言語対応の容易さ

## 3. システム構成

### 3.1 コンポーネント構成
1. データ収集システム
   - Webクローラー
   - コンテンツ分析
   - データ検証

2. ナレッジベース
   - 生データ保存
   - 構造化データ
   - メタデータ管理

3. クイズ生成エンジン
   - トピック選択
   - 質問生成
   - 選択肢生成
   - 解説生成

### 3.2 データフロー
1. 情報収集
   ```
   Webソース → クローラー → 生データ → 分析 → ナレッジベース
   ```

2. クイズ生成
   ```
   ナレッジベース → トピック選択 → GEMINI処理 → クイズ生成 → 検証 → 提供
   ```

## 4. クイズ設計仕様

### 4.1 クイズ構造
```typescript
interface QuizQuestion {
  id: string;
  question: string;
  options: {
    text: string;
    isCorrect: boolean;
    explanation: string;
  }[];
  difficulty: 'beginner' | 'intermediate' | 'advanced';
  category: string;
  source: string;
}
```

### 4.2 難易度基準
- beginner: 基本的な用語、一般的な知識
- intermediate: やや専門的な知識、具体的な特徴
- advanced: 専門的な知識、詳細な違い

### 4.3 カテゴリー
- 基礎知識（basic）
- 豆の特徴（beans）
- 焙煎（roast）
- 産地（origin）
- 抽出（brewing）
- 保存（storage）

## 5. 品質管理

### 5.2 クイズの品質

### 5.3 フィードバックループ
